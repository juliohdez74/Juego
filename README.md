# 🎮 Memory Game - TICs 🖥️

Un juego de memoria interactivo y divertido para estudiantes de TICs, donde dos equipos compiten por encontrar pares de palabras relacionadas con tecnología.

## 🎯 Características

- ✨ **Modo de dos equipos**: Divide el grupo en equipos que compiten entre sí
- 🎵 **Música de fondo**: Efectos de sonido y música retro de videojuegos
- 🎨 **Diseño moderno y colorido**: Interfaz atractiva y responsiva
- 📱 **Compatible con dispositivos**: Funciona en computadoras, tablets y teléfonos
- 🏆 **Sistema de puntuación**: Contador de puntos por equipo
- 🎪 **Palabras sobre TICs**: Incluye términos como Hardware, Software, Internet, etc.

## 🚀 Cómo jugar

1. **Selecciona un equipo** (Equipo 1 o Equipo 2)
2. **Haz clic en "Reiniciar Juego"** para comenzar
3. **Voltea las tarjetas** para encontrar pares de palabras iguales
4. **Gana puntos** cada vez que encuentres un par correcto
5. **El equipo actual cambia** cuando no encuentres un par
6. **¡Gana el juego!** cuando encuentres todos los 8 pares

### Mecánica del juego:
- Cada par encontrado = 1 punto para el equipo actual
- Si no coinciden las cartas, el turno pasa al otro equipo
- El juego termina cuando se encuentren todos los pares
- ¡Gana el equipo con más puntos!

## 🎵 Controles de Audio

- Utiliza el botón 🔊 en la esquina inferior derecha para silenciar/activar la música
- La música se reproduce automáticamente (si el navegador lo permite)
- Efectos de sonido en: voltear cartas, encontrar pares, ganar puntos

## 🎨 Personalización

Puedes editar el archivo `script.js` para:
- Cambiar las palabras del juego (array `ticWords`)
- Ajustar la velocidad de animaciones
- Modificar los volúmenes de sonido

- **Botón Reiniciar**: Comienza un nuevo juego
